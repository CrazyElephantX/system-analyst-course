# system-analyst-course

# Облако

- [perplexity](https://www.perplexity.ai/) - Для поиска информации и анализа конкурентов, а так же для проверки своих материалов на полноту. Использую лабораторию для создания различных онлайн стендов
- [deepseek](https://chat.deepseek.com/) - для работы с текстом и различных бытовых задач, в которые не очень сильно хочется погружаться, мощная и при этом бесплатная альтернатива другим моделям
- [sourcecraft](https://sourcecraft.dev/) - Плагин для VS Code, который помогает экономить время при написании сиквенсов и openapi спецификации, а так же при написании любого другого кода или анализа его
- [giga.chat](https://giga.chat/) - Использую в основном для генерации картинок. Хотя функционально умеет очень многое (даже создание презентаций!), в качестве ответов пока уступает узкоспециализированным аналогам.
- [floot](https://floot.com/) - для создания первой версии макетов и возможности подумать визуально, тут надо быть аккуратным что бы не выложить что-то что попадает под NDA
- [chatGPT](https://chat.openai.com/chat) - для генерации текста, а так же для проверки своих материалов на полноту и корректность. Использую для генерации текста и для проверки своих материалов на полноту и корректность
